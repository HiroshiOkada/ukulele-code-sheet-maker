# ウクレレ・コードシートメーカー

UTF-8のテキストから、歌詞・ストローク・4弦のコードダイアグラムを並べたA4縦のPDFを生成するCLIです。ダイアグラムと矢印はベクター描画、日本語フォントはPDFに埋め込みます。

## 実行

Python 3.12以上とuvを使用します。

```powershell
uv sync
uv run uke-sheet examples/twinkle.uke -o output/pdf/twinkle.pdf
uv run uke-sheet examples/notation-demo.uke -o output/pdf/notation-demo.pdf
```

`-o`を省略すると入力ファイルの拡張子を`.pdf`に置き換えたパスに保存します。既存の出力PDFは、生成に成功した場合に置き換えます。入力ファイル自身への上書きは拒否します。

```powershell
uv run uke-sheet examples/twinkle.uke --check
uv run uke-sheet --list-chords
uv run uke-sheet examples/twinkle.uke --bars-per-row 3
uv run pytest -q
```

`--check`は記法のみを検証します。印刷幅の確認はPDF生成時に行います。

WindowsではMSゴシックを自動検出します。その他の環境ではIPA/IPAexゴシックの代表的なパスを探します。見つからない場合は`--font /path/to/Japanese.ttf`で日本語のTrueTypeフォントを指定してください。TTCは先頭のフォントを使用します。CFF形式のOTFには対応しません。

## サンプル曲

`examples/twinkle.uke`は伝承曲「きらきら星」の旋律を想定したC・F・G7による簡易伴奏です。2音ずつを中心にゆったり進む24小節の4/4練習用アレンジです。既存の日本語訳詞は使用せず、日本語の配置確認用に今回のオリジナル歌詞を付けています。旋律や五線譜は出力しません。

`examples/notation-demo.uke`は曲ではなく、拍の分割、反復、消音弦、ハイポジション、明示的な改ページを確認するサンプルです。

## 入力記法

```text
タイトル: 練習曲
拍子: 4/4
テンポ: 92
ストローク: D - (D U) (D U)
フォーム C_high = 5433 表示=C

[Aメロ]
| C"風の" -"音を" F"聞き" G7"ながら" |
| C"歩こう" | F G7 | C_high | - |
```

### 小節と拍

`|`で囲んだ部分が1小節です。項目を均等な長さに分割します。

| 4/4の入力 | 意味 |
| --- | --- |
| `\| C \|` | Cを4拍 |
| `\| F G7 \|` | FとG7を2拍ずつ |
| `\| C Am F G7 \|` | 1拍ずつ |
| `\| C - - G7 \|` | Cを3拍、G7を1拍 |
| `\| C - F (G G7) \|` | 最後の1拍だけ半分に分割 |

`-`は直前の和音を継続します。最初の小節の先頭には使えません。コード名を再度書くとダイアグラムを再掲します。段頭で継続する場合にも確認用として再掲します。

対応拍子は2/4、3/4、4/4、6/8（既定は4/4）。小節内の項目数は分子の約数です。4/4なら1・2・4項目、3/4なら1・3項目、6/8なら1・2・3・6項目となります。6/8では基本単位を八分音符として扱います。テンポ表示は入力値の注記で、再生機能はありません。

括弧内は2または4項目に等分し、最大4段まで入れ子にできます。三連符、弱起、曲中の拍子変更は初版では扱いません。

### 歌詞

コードまたは`-`の直後に`"歌詞"`を置きます。引用符との間の空白は任意です。その項目の開始位置に配置されます。歌詞内部の文字ごとのタイミングは指定しません。

引用符中では空白、`#`、`|`も文字として扱います。引用符そのものは`\"`、バックスラッシュは`\\`と記述します。歌詞の外では、行頭または空白の後の`#`から行末までがコメントです。`F#`などのコード名はコメントになりません。

### ストローク

| 入力 | 意味 |
| --- | --- |
| `D` | ダウンストローク（↓） |
| `U` | アップストローク（↑） |
| `-` | 弾かずに伸ばす（〜） |
| `.` | 空振り・待機（表示なし） |
| `x` | ミュート打音（×） |

本文より前の`ストローク:`は共通パターンです。コードと独立した時間列なので、和音の継続中にも弾き直せます。括弧で八分・十六分などに分割できます。

コード行の直後の指定は、その行だけを上書きします。小節線なしなら同じパターンを行全体に適用し、小節線ありならコード行と同じ小節数を指定します。

```text
| C | G7 |
ストローク: | D - D - | D - - - |
```

### フォーム

内蔵フォームは`--list-chords`で確認できます。未登録コードを推測して表示することはせず、フォーム定義を求めるエラーを出します。

```text
フォーム C = 0003
フォーム C_high = 5433 表示=C
フォーム C_muted = x003 表示=C
フォーム C_high15 = [0, 0, 0, 15] 表示=C
```

定義は本文より前に置きます。左から**G・C・E・A弦**、`0`は開放、`x`は消音、数字は0〜24フレットです。10以上の場合はカンマ区切りの角括弧形式を使います。ハイポジションでは開始フレット番号を表示します。High-G/Low-Gとも同じ押弦位置を利用できます。運指番号、セーハの帯、別チューニングは初版では扱いません。

PDFのダイアグラムは縦向きから90度反時計回りに回転した横向きです。ナットは左側、弦は上からA・E・C・Gで、フレット番号は左から右へ増えます。コード名・弦名・開始フレット番号は読みやすい正立の文字で表示します。入力するフォームの弦順は従来どおりです。

### 構成と印刷

- `[サビ]`などのセクション見出しで改段します。
- `|: C | F | G7 | C :|`は2回反復、`:|x3`は3回反復です。
- 反復は複数の入力行をまたげます。入れ子や1番・2番括弧には未対応です。
- 入力行の改行ではPDFを改段しません。`@改段`、`@改ページ`で明示できます。
- 最大4小節を1段に配置し、歌詞や図が多い場合は小節数を減らします。`--bars-per-row`で上限を1〜8に変更できます。
- 小節を途中で分割せず自動改ページします。長すぎる歌詞などで1小節がページ幅を超えると、該当行を示してエラーにします。

## 開発構成

- `parser.py`: 記法の検証と分数による拍位置の計算
- `render.py`: 幅計算、ページ配置、ダイアグラムとPDFの描画
- `cli.py`: 入出力と利用者向けのエラー表示
- `tests/`: 記法、エラー、A4寸法、日本語フォント埋め込み、複数ページの検証

依存追加は`uv add`、実行は`uv run`を使用します。生成PDFは`output/pdf/`、目視確認用画像は`tmp/pdfs/`に置き、Git管理から除外しています。
